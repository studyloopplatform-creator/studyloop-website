Guida all'installazione
Windows · v0.1.8
Come installare
1

Avvia il file scaricato

Fai doppio clic su StudyLoop_0.1.8_x64-setup.exe
Si avvierà il programma di installazione.

2

Gestisci l'avviso di Windows SmartScreen

Windows potrebbe mostrare il messaggio "PC protetto da Windows". Per procedere:

  • Clicca "Ulteriori informazioni"
  • Poi clicca "Esegui comunque"

L'installazione partirà normalmente.

3

Completa l'installazione

Segui le istruzioni a schermo. Al termine troverai StudyLoop nel menu Start e una scorciatoia sul Desktop.

Perché Windows mostra un avviso?

Windows SmartScreen visualizza questo messaggio per le applicazioni indipendenti non ancora molto diffuse o prive di firma digitale costosa. Non è un segnale di pericolo.
