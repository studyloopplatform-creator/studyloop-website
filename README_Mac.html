Guida all'installazione
macOS · v0.1.8
Come installare
1

Apri il file scaricato

Fai doppio clic su StudyLoop_0.1.8_universal.dmg
Si aprirà una finestra con l'icona dell'applicazione.

2

Trascina in Applicazioni

Trascina l'icona di StudyLoop nella cartella Applicazioni mostrata nella stessa finestra.

3

Primo avvio

macOS mostra un avviso di sicurezza la prima volta. Per procedere:

  • Clic destro sull'icona di StudyLoop in Applicazioni
  • Seleziona "Apri" dal menu
  • Nella finestra che appare, clicca "Apri"

Dalla volta successiva basta doppio clic normale.

Perché macOS mostra un avviso?

macOS visualizza questo messaggio per tutte le applicazioni non distribuite tramite l'App Store ufficiale. Non è un segnale di pericolo — è una misura di protezione standard del sistema operativo.
